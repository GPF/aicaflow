# Changelog

## 0.2.0

- First generic AICAflow release with the strict bank-bound AFB/AFX model.
- Ships a verified ARM7 firmware image so ordinary builds do not need ARM7
  tools.
- Splits the SH4 host into allocator, DMA, flow, instance, IPC, bank and DSP
  units.
- Includes self-contained quickstart, DSP, dynamic-SFX and tuner examples.
- Removes DKR, N64, OoT, VGM, legacy project and historical-format material
  from the public main branch.
